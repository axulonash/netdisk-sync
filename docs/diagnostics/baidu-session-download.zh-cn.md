# 百度直连第三批：令牌会话与文件下载（2026-10-06）

后续已接入[授权与目录检查入口](baidu-connection-entry.zh-cn.md)及
[桌面 HTTPS 下载传输](baidu-desktop-download.zh-cn.md)。下文记录第三批完成时的状态。

## 令牌会话

新增 src/native/baiduSession.ts，初始令牌从调用方提供的配置副本载入。
距过期不足 30 秒时尝试刷新；并发调用共享同一次刷新和保存任务，保存成功才返回新 access token。

刷新轮转后保存失败，保留待保存的新令牌，下一次调用先重试保存，避免重新使用失效旧 refresh token。
如果待保存候选也过期，使用候选的轮转 refresh token 再刷新。没有无限刷新循环。
令牌在保存过程中到期时，不把过期令牌返回给下载操作。

logout 立即清除内存会话，使用版本标记阻止旧刷新结果恢复登录；持久化清除排在已经开始的保存之后。
退出是本地会话退出，不是平台侧吊销授权。清除持久化失败时明确报错，内存仍退出；
磁盘原凭据可能仍存在，下次进程启动必须由集成层处理该失败，不能宣称已经永久注销。

刷新及保存回调均为注入边界。模块不直接修改插件设置，也不完成浏览器登录或替换账号。
不同会话实例之间尚未协调持久化；未来切换账号应先结束旧会话，再建立新会话。
不依据所有 HTTP 错误盲目刷新，平台提前撤销而 expiresAt 未到时仍需集成层的有界恢复策略。

## 文件下载

新增 src/native/baiduDownload.ts，使用会话获取的 access token 查询 xpan/multimedia 的 filemetas。
请求 fsids 保留十进制字符串精度；响应必须对应同一个文件 ID，若返回大小／目录标记也会校验。
然后取得 dlink 并下载完整文件，要求最终 HTTP 200、ArrayBuffer 和预期字节长度一致。

第一跳只接受 HTTPS 的 pcs.baidu.com 子域或 baidupcs.com 域及子域，不接受用户信息、片段或非标准端口。
在该初始链接加上 access_token；后续最多五次重定向，逐跳核验同样的域名边界并移除 access_token，
不添加 Cookie 或 Authorization，仅使用固定 User-Agent。临时下载链接不缓存。

binary transport 必须采用手动重定向并将 Location 交回模块。当前尚未绑定真实 Obsidian 传输，
requestUrl 能否满足此契约需要验证；不能把模块验证当作实际网络层已逐跳检查。
这些域名来自当前参考实现和夹具，真实账号如返回其他合法 CDN，需核验后扩展，不能静默开放任意域。
某些受信域的跳转若仍要求 OAuth token，当前会因不传递而失败，需实测区分首跳与最终签名链接。

下载参考：[OpenList 百度下载实现](https://raw.githubusercontent.com/OpenListTeam/OpenList/main/drivers/baidu_netdisk/util.go)。
官方文档本轮仍未成功抓取，未使用真实账号验证；参考实现不是官方稳定接口承诺。
错误信息不包括原始描述、凭据 URL 或底层传输消息，不输出令牌日志。

## 仍需接入的部分

模块尚未接入 settings、getClient、requestUrl 或实际浏览器授权回调；当前百度仍不能在界面中选择并同步。
没有完成账号身份验证、上传、删除、移动、远端哈希验证或移动端验收。
下载按 ArrayBuffer 全量载入内存，尚未提供流式下载；大小一致不能证明内容哈希正确。
保存回调的失败可能已有外部副作用，模块只能控制内存状态和调用顺序，不能替外部存储提供事务。

下一批绑定真实传输并实现登录会话入口，完成只读账号验收后再推进写入适配器。
