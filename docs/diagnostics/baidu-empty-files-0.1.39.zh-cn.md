# 0.1.39 百度网盘空文件处理

真实测试出现「当前百度同步不支持未加密的空文件」：预扫描得到 103 项（75 个上传、28 个文件夹），但准备阶段整体中止，已完成 0 项。原因是 0.1.38 在计划预检查中将任何未加密空文件视为全局阻断条件。百度网盘上传接口不接受 0 字节文件，因此不能把这类文件按原样上传。

0.1.39 在执行计划之前将需要传输、且本地大小为 0 的未加密文件标记为跳过。其他文件和文件夹继续同步；如果网盘上已有同名文件，不覆盖、不下载到这个本地空文件，也不更新它的同步历史。同步结果为「部分完成」，进度与诊断摘要显示跳过数量，展开同步记录可见路径。用户给空文件写入内容后，下一次同步会重新纳入计划。加密文件不受此限制，因为加密后的文件非空。

远端目录删除及超过 64 MiB 的文件仍保留原有预检查。百度实际上传仍需用户实测确认；本地测试验证了空文件跳过、其他文件正常上传、已有远端内容保留及记录状态。

验证：Mocha 649 项、WebDAV 118 项全部通过，TypeScript 检查及生产构建通过。ZIP 仅包含 main.js、manifest.json、styles.css，版本及 CRC 校验通过。
