# 0.1.28：WebDAV 同步目录格式修复

## 根因

填写 `/home/test` 时，SDK 将请求路径规范化为 `/home/test`，但插件使用未处理的目录值构建扫描范围，预期前缀成为 `//home/test/`。即使服务器目录已建立，返回的列表仍被判定为范围之外，扫描立即终止，文件上传尚未开始。

填写 `home/test/` 时，结尾斜杠也会导致后续子路径拼接不一致。

## 修复

在 WebDAV 适配器创建时统一移除同步目录开头和结尾的斜杠，让网络请求、扫描校验和文件传输共用同一内部路径。`/home/test`、`/home/test/`、`home/test/` 均对应同一个远端目录，不迁移或删除原文件。

## 验证与实测

新增真实 HTTP 回归测试，覆盖上述三种目录格式：空目录扫描、创建子目录、上传嵌套文件、再次扫描和读取内容。测试在修复前全部失败，修复后全部通过。

安装 0.1.28 后，保留现有配置和同步历史，完全退出并重新打开 Obsidian，再执行一次同步。检查扫描是否完成、计划上传数量是否大于零，以及远端文件内容是否与本地一致。若仍失败，请提供新一条同步历史的诊断摘要；不要提供账号密钥。

完整验证：552 项主测试、113 项 WebDAV 测试通过；TypeScript 类型检查与生产构建通过。构建保留 5 项现有依赖及包体积警告。真实用户服务器仍待更新后验证。
