# 百度桌面实验同步：配置与验收

桌面设置页已提供“百度网盘（桌面实验）”服务，可通过现有同步命令进行预览和手动同步。
插件直接请求百度 API，不依赖网关、中转或 PRO 账户。智能冲突仍沿用原 PRO 功能检查。
自动定时、启动及保存触发的百度同步均拦截，移动端仅保留授权和只读检查。

## 安装和首次配置

1. 按[本地开发与部署指南](../how_to_debug/local-development.zh-cn.md)使用 Node 26.10.0，执行 `npm ci --ignore-scripts`、`npm run build`。
2. 把 `main.js`、`manifest.json`、`styles.css` 复制到专用测试仓库的 `.obsidian/plugins/remotely-save-next/`，重载插件。
3. 打开“百度网盘 · 桌面手动同步（实验）”，填写自己的百度应用 API Key 和 Secret Key，在官方授权页登录，回填本次授权码并保存。
4. 在“检查远端目录”中填写已存在的应用专用测试目录绝对路径，例如 `/apps/你的应用目录/测试仓库`。点击“检查并保存同步目录”。不会创建根目录或写入笔记。
5. 在同步服务选择器中选择“百度网盘（桌面实验）”。初次测试选择普通冲突处理，不启用智能冲突。
6. 先执行原有的同步预览/生成计划命令，查看插件保存的同步计划。确认目录及新增、修改、删除项后，再执行手动同步。

此前实验入口保存的授权没有同步身份信息，需要重新授权才能完整同步；只读检查仍可使用。
看到 `reauthorize_required` 时重新授权，`remote_root_required` 时检查并保存目录，
`credential_binding_mismatch` 表示凭据与授权身份不匹配，应重新授权，不要手工修改绑定字段。
若 PRO 智能冲突报错，改用普通冲突处理，或按原项目方式配置该高级功能。

## 历史如何隔离

每次重新授权生成随机授权会话标识，不是百度账号 UID。
普通令牌刷新保留该标识，并更新凭据绑定；重新授权即使登录同一个百度账号，也使用新 profile。
旧 profile 保留，不删除，也不自动合并进新 profile。

百度 profile 纳入会话标识、应用、规范化远端根目录、密码与加密方法，最终只保存 SHA256 标识，
不把 token、Secret Key、密码或目录原文放入 profile 名称。
更换账号、目录或加密配置不会沿用旧 profile 的删除历史。
导入时只换 token 却保留旧身份绑定会被拒绝，避免把其他账号误认作原会话。
完整原配置备份恢复会恢复其原 profile；凭据仍包含在设置备份内，设置混淆不等于加密。

适配器在操作前后检查作用域。已经发出的远端修改无法撤销；若操作结束时作用域变化，
不会记录同步成功。出现 `outcomeUnknown` 或 `sync_scope_changed` 时先核对远端实际状态。
退出只清理本地凭据，不等于在百度平台撤销应用授权。

## 实际验收顺序

使用几个可丢弃笔记，先检查预览，再分别测试：

- 新增一个普通笔记及一个子目录中的笔记，同步后核对百度内容。
- 再同步一次，确认不会重复上传。
- 修改内容，再同步并核对版本。
- 删除一个笔记，保留另一个笔记，预览确认单项删除后执行。
- 模拟断网或权限不足，确认报错且重试前重新检查远端状态。
- 如需加密，使用独立远端目录选择 OpenSSL，核对文件名、内容加密和下载恢复。

本地仓库完全清空时，原引擎优先从远端恢复，不会把全部远端文件直接判为删除。

当前限制：单文件上传/下载最多 64 MiB；空明文文件上传不支持（OpenSSL 加密空笔记已在夹具验证）；
Rclone 百度同步暂未开放；不支持重命名 API；扫描超出上限报错，不返回部分清单。
预览读取目录和生成计划，不等于上传、删除权限或完整实际同步验收通过。
