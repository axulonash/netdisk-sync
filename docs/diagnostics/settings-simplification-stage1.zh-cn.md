# 设置页精简第一批：可用服务收敛与分组折叠

## 已确认的接入要求

用户明确要求百度网盘和夸克网盘由插件直接登录，不依赖 AList／OpenList 或其他 WebDAV 桥接服务。
当前仓库没有这两个网盘的适配器。本轮不新增不可用的选择项，也不把 WebDAV 改名冒充原生支持。
后续需要分别核实登录授权、令牌维护、列表分页、上传下载、删除和平台兼容性。

## 本轮实现

- 新配置默认 WebDAV；已有配置的 serviceType 仍覆盖默认值，不自动迁移。
- 服务下拉框仅展示 WebDAV，以及当前或先前正在使用的旧服务。
- 用户离开旧服务时，将旧服务标识保存到可选 legacyServiceType 字段，重开设置或重启后可切回。
  旧服务配置、同步适配器、授权和依赖暂时保留；本轮不是旧后端的物理删除。
- WebDAV 的地址、账号、密码、远端目录和连通性测试保持可见；认证方式、扫描深度、自定义头折叠到高级连接选项。
- 加密、自动同步、启动同步、保存后同步及同步方向保持可见。
- 大文件过滤、路径过滤和状态栏操作移入默认折叠的高级设置；导入导出、账号订阅和调试亦默认折叠。
- 使用原生 details／summary，保留键盘交互；展开与折叠不重建控件，不改变设置回调。
- 更新简体、繁体和英文文案，移除服务选择说明里的冗长平台列表。

折叠状态不写入配置，下次打开设置恢复折叠。折叠内已有选项仍按原配置生效。
切换服务不迁移远端文件，沿用现有服务切换与同步流程；本轮未改动冲突、删除保护或加密策略。
