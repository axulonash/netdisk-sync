# 0.1.31：桌面 WebDAV 速度显示

进度条下增加上传和下载速度，每秒更新，单位自动切换 B/s、KB/s、MB/s。统计所有并行 WebDAV 文件传输；大文件未完成时也会更新。扫描阶段及同步结束后隐藏，无数据传输时回到零。暂停后若当前请求仍在传输，继续显示实际速度，等待中的请求不会产生虚假速度。

下载按实际读取的文件正文计数；上传按底层 socket 已写出的字节估算，扣除 HTTP 请求头，并限制在文件正文长度内。速度表示客户端的传输活动，不代表服务端已确认写入；文件成功数量仍以校验完成为准。压缩下载统计解压后的文件字节。

本轮只接入桌面 WebDAV；手机端和其他网盘尚未提供实时字节回调，因此隐藏速度而不是用完成文件的大小推算“实时”速度。

用户服务器经 Cloudflare Tunnel。现有四个 HTML 下载多出 367–605 字节，疑似代理修改内容，但未取得远端正文对比，不能归因于 Tunnel 本身。本轮不绕过大小校验、不改动用户 HTML 文件，也未宣称修复下载内容差异或大文件上传网络错误。
