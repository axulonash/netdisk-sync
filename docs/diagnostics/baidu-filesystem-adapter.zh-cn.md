# 百度文件系统适配层（实验）

本轮将现有百度协议能力组合为 `src/fsBaidu.ts` 的 `FakeFsBaidu`，实现同步引擎使用的 `FakeFs` 接口。
当前只在开发测试中实例化；尚未加入 `getClient`、同步服务选择器或自动同步。
不能把接口完成等同于真实账号同步验收完成。

## 已实现的行为

- `walk` / `walkPartial` 完整递归扫描，转换为相对路径的 `Entity`；目录键保留末尾 `/`。
- `stat` 查询目标所属目录，核对精确路径及文件/目录类型，不依赖旧扫描缓存。
- `readFile` 在同一次连接操作中查询文件 ID、获取下载元数据并下载；各阶段检查账号。
- `mkdir` / `writeFile` 成功后重新查询元数据，核对返回 ID，上传还核对大小。
- `rm` 保留目录与删除协议的严格确认要求；失败继续抛出。
- 并发文件操作排队执行，失败不阻塞后续队列。适配器绑定创建时的账号；外部更换登录配置后，旧适配器拒绝后续操作，必须新建适配器。
- 本会话成功保存的令牌轮转保持账号身份，正常刷新不会导致后续队列误报账号切换。
- `checkConnect` 只扫描，不使用基类会创建、覆盖及删除测试文件的检查流程。

绝对远端根目录必须是账户根目录下的具体目录。相对键不允许账户根、绝对路径、空路径、
`.` / `..`、重复分隔符、控制字符或非法 UTF-16 代理项；不自动截短或替换文件名。

修改操作已经提交，但元数据复核失败时，返回 `mutation_verification_failed`，
并标记 `outcomeUnknown: true`；不会自动重发。先核对远端实际状态。

## 当前边界与后续工作

上传会明确请求覆盖同名文件，这是同步写入接口所需行为；尚未由真实同步计划调用。
当前时间信息使用已核对的服务端时间，尚需验证百度本地时间字段与同步历史的配合，避免重复上传。
上传与下载仍受此前实现的单文件 64 MiB 上限约束，空文件上传暂不支持。
重命名明确返回 `rename_unsupported`，不会以复制后删除模拟。
退出授权仅清除本地登录信息，未调用百度平台撤销授权接口。
扫描沿用连接入口的 100 页/单目录、总计 10000 项上限，超限报错，不返回部分结果。

下一步先通过真实同步计划、加密包装及同步历史测试，再接入服务选择和设置页。
真实账号验收须使用专用测试仓库及测试目录，先审阅同步计划，再验证新增、修改和删除。
夸克网盘适配器尚未实现。

## 本地验证

按[本地开发和部署指南](../how_to_debug/local-development.zh-cn.md)准备 Node 环境。
适配器本轮尚未作为 Obsidian Console 接口公开，先运行源码测试：

```sh
npx mocha --import=tsx tests/native/fsBaidu.test.ts tests/native/baiduConnection.test.ts tests/native/baiduSession.test.ts
npx tsc --noEmit --skipLibCheck
npm run test:baseline
npm run build
```

夹具使用真实连接及协议客户端，替代外部 API 的传输层；覆盖扫描失败、精确路径查找、
账号切换、正常令牌轮转、并发排队、提交后元数据复核失败和删除单项失败。

2026-10-07 验证结果：常规测试 314 项、WebDAV 回归 96 项全部通过；
类型检查通过，生产构建通过（5 条既有警告）。适配层新增 28 项测试。
静态复核已完成，修正了正常令牌轮转及保存期间新请求入队的误判。
真实账号、完整同步和实际 Obsidian 运行时尚未验收。
