# 0.1.30：WebDAV 当前笔记本目录与桌面传输

同步目录输入父目录，例如 `/home/Drive`。插件自动附加当前 Obsidian 笔记本名称；当前笔记本为“我的笔记本”时，目标为 `/home/Drive/我的笔记本`。

旧配置 `/home/Drive/test` 首次迁移时提取父目录 `/home/Drive`，再拼接当前笔记本名称。迁移不会移动或删除旧目录里的文件。目标变化后需重新测试连接，旧目标的同步记录不会作为新目标的比较基准。用户已说明会自行清理调试期间混入的文件，本次不清理这些文件。

桌面端 WebDAV 改为可关闭底层连接的传输：30 秒无网络活动结束请求；GET/PUT 总时限 10 分钟，其他请求 60 秒。暂停在安全检查点生效；停止会中止当前读取，已提交的写入等待有界结果。无法确认的写入沿用结果核对机制，不盲目重传。手机端仍沿用原传输。

下载重定向关闭前一跳的连接；跨站不转发授权信息，但保留文件版本校验头。HEAD 和无正文响应不执行解压。OPTIONS 能响应停止操作。

回归测试用本地 HTTP 服务模拟无响应、传到一半、上传响应丢失、重定向、压缩与中止，并通过真实 WebDAV SDK 检查读写及版本校验。未连接用户服务器，不能据此确定此前特定 HTML 卡住的服务端原因。

更新后完全重启 Obsidian，确认完整目标路径包含当前笔记本名称，再测试连接和同步。若仍失败，请提供本轮诊断摘要及错误阶段，无需提供密码或带授权参数的链接。
