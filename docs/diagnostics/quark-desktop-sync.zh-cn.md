# 夸克桌面实验同步

本插件直接请求夸克的扫码登录与文件接口，不使用 AList、OpenList 或其他网关，
不提供手工 Cookie 导入。扫码时使用公开网页的 client_id=532；二维码由插件本地生成，
用官方夸克 App 扫码确认，再点击“检查登录”。二维码和服务票据仅在内存保留，
五分钟过期或关闭弹窗即失效。会话凭据保存在插件配置中，配置混淆不等于加密。

## 配置和验收

1. 按[调试环境说明](../how_to_debug/local-development.zh-cn.md)安装到专用测试仓库。
2. 桌面端选择“夸克网盘（桌面实验）”，展开当前网盘设置，点击“扫码登录”。
3. 在夸克创建专用测试目录，例如 `/Obsidian测试`，填写路径并“检查并保存”。
   该检查只读取目录，不会创建或删除文件，不允许选账户根目录 `/`。
4. 点击“创建测试文件并验证覆盖”。该操作写入随机命名的测试文件，再上传不同长度的内容，
   下载比对字节、检查原文件 ID，最后删除并确认不存在；只有全部通过才允许覆盖已有文件。
5. 先用插件原有的同步预览命令检查计划，再手动同步。用两份专用测试仓库验证上传、
   下载、更新、子目录和删除；开启 OpenSSL 后重新验证。不要先用于唯一一份真实笔记。

覆盖验证失败不会启用覆盖能力，错误只显示固定错误码，不显示原始接口消息和会话。
接口可能自动改名或留下 `rs-overwrite-check-*` 测试文件；检查远端残留后再处理。
验证绑定当前会话和目录，重新扫码或换目录后需重新验证。
覆盖检查与本插件同步互斥；严格匹配 `rs-overwrite-check-<32位随机字符>.bin` 的文件名
保留给诊断用途，所有设备的扫描均跳过这种文件，避免中断检查后把残留当笔记同步。
正式上传不会先删原文件；上传后读取目标元数据并下载核对内容，失败不会被记为同步成功。

## 能力边界

- 桌面手动同步与预览；自动、启动时和保存后同步尚未开放，设置页隐藏对应选项。
- 扫码登录、完整分页扫描、下载、目录创建、新增文件、经验证的同名覆盖和确认删除。
- 明文或 OpenSSL 加密；Rclone 尚未开放。空明文文件暂不支持，加密后的空笔记可上传。
- 单文件 64 MiB；单目录最多 100 页、整个扫描最多 10000 项。超限或分页矛盾明确失败，
  不把截断的扫描当完整扫描。接口成功不等于写入成功，异步删除须等待并检查结果。
- 目录和相对路径禁止空片段、`.`、`..`、控制字符和损坏 Unicode，保留合法中文、百分号和长名称。
- 独立 rename 接口尚未实现；原有同步引擎处理普通笔记更名通过新增和删除完成。
- 登录、目录、加密设置的变化会停止旧客户端；同步历史按登录身份、目录和加密设置隔离。
  重新扫码会得到新身份，旧历史保留但不混用。
- 文件下载及 OSS 上传仅允许 TLS 和指定域名，不自动携带凭据跟随重定向，
  OSS 上传不发送夸克会话 Cookie。每个请求有总超时与响应大小限制。

**尚未在真实夸克账号和 Obsidian GUI 中验收。** 私有 Web 接口可能变化，
本地协议夹具无法证明服务端支持 `same_path_reuse`；因此该能力必须现场探测，不能默认开启。
若官方服务不支持安全覆盖，这一网盘仍不能承担完整双向同步，不能靠先删除旧文件来绕过。
