# 0.1.43 同步错误说明与处理方法

用户通过移除文件名中的 🚀 确认该字符触发百度 filemetas/rename 的 -7 错误；同一 3985 字节文件在移除后上传通过。此版调整错误说明，不自动改名或宣称所有表情均不支持。

重命名被百度拒绝且路径含补充平面字符时，保留原始接口和子错误码，同时添加受限的布尔上下文，提示在 Obsidian 修改文件名或目录名中的表情、特殊字符后重试。没有这类上下文的 -7 提示检查名称和权限，不猜测为表情限制。失败相对路径仍列在同步记录中。

常见错误按已知证据给出原因和动作：登录失败检查账号并重新登录；403 检查目录权限；404 检查地址、文件与目录路径；429 稍后同步；5xx 服务暂不可用、稍后重试。百度网络中断、文件大小限制、上传准备异常、内容校验异常、改名结果未确认和账号变化也补充下一步。跳过空文件的记录说明先写入内容再同步。未知错误引导查看未完成文件与诊断摘要，不笼统断言是网络或权限。

错误码及受限接口上下文保留用于诊断，不显示 Cookie、令牌、原始接口响应或带授权参数的链接。同步策略与完整性检查保持原有行为。
