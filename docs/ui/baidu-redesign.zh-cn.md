# 百度网盘简化页面（0.1.4）

沿用 WebDAV 的原生 Obsidian 布局、同步设置/同步记录页签、输入框内密钥显隐图标与分隔线。

默认页面：同步服务、百度登录状态、同步目录和测试连接、冲突处理、立即同步。
登录区域默认折叠，通过“登录百度”或“重新授权”打开；填写自己的 API Key、Secret Key，打开百度官方授权页并回填本次授权码。授权码不会写入设置，10 分钟后失效。

百度没有 WebDAV 服务器地址或账号密码输入。测试连接对目录做只读检查，成功后保存同步目录；状态灯显示结果。保留已有目录，新安装默认建议 `/apps/remotely-save-next`，该目录需与自己的开放平台应用权限匹配并已存在。

现阶段仅支持桌面手动同步，不显示保存时同步或定时同步。移动端保留授权及只读目录检查，禁用同步与目录保存。
高级设置折叠保留加密、排除规则、调试工具，并提供同步计划预览。原生限制仍保留：单文件最多 64 MiB、空明文文件暂不支持、加密仅支持 OpenSSL。

同步记录保留最近 100 次，先显示 20 次，可加载更多；包括时间、状态、耗时、实际完成的上传/下载/删除统计，展开后显示文件目录树。预览、授权和连接检查不写入同步记录。账号和目录范围通过现有百度 profile 隔离。
大量变更须本次确认，确认后重新扫描；文件或配置变化时拒绝旧计划。

## 验收

1. 替换安装包内三个文件，保留 data.json，重新启用插件，选择百度网盘。
2. 检查原有授权和目录保留；未登录时完成官方授权。
3. 修改同步目录，确认立即同步暂不可用；测试连接成功后目录保存、显示绿灯；失败显示红灯且不替换旧目录。
4. 展开高级设置，先预览计划，再手动同步测试文件，检查远端内容与同步记录的计数和目录。
5. 用两个不同内容的文件版本验证“保留双方副本”；大量变更验证取消确认及等待确认期间修改文件的保护。

本地自动测试与构建已验证；真实百度账号及 Obsidian 内操作需按以上步骤验收。

## 0.1.5 授权入口修复

打开授权页仅要求 API Key；换取令牌仍需 Secret。桌面端优先使用系统浏览器，移动端使用浏览器跳转；提供手动授权链接、获取应用信息入口，未配置 Key 时在授权区就近提示并聚焦输入。当前尚无项目统一注册的百度应用，因此这次修复不代表普通用户免配置的一键登录已完成。

官方 OAuth 文档：https://openauth.baidu.com/doc/doc.html 。百度网盘官方 SDK 的设备授权换取令牌也要求 client_secret：https://github.com/baidu-netdisk/mcp/blob/main/src/baidu-netdisk/openapi_client/api/auth_api.py 。

## 0.1.6 目录检查错误反馈

红点悬浮提示保留已识别错误类型，并提供安全的百度 errno 或 HTTP 状态码。不显示原始异常文本、令牌或密钥。通用提示不能确定用户本次实际失败原因，需重新测试取得错误码及目录路径再判断。9 项百度界面检查、类型检查和构建通过。

## 0.1.7 连接成功后同步按钮禁用修复

复现路径：输入 `/apps/`，后端去掉末尾斜杠保存 `/apps`，旧界面字符串比较不相等，导致显示绿点却无法同步。成功保存目录后，界面采用后端实际保存的规范路径，并同步更新测试状态。禁用时按钮悬浮提示给出具体原因。

## 0.1.8 三步设置与手机提示（当前行为）

页面按“登录百度网盘 → 选择同步文件夹 → 开始同步”排序，显示每步状态，突出当前下一步按钮。首次打开直接显示登录步骤；授权码在打开授权页后显示。应用仅需填写 AppKey 与 AppSecret，AppID、SignKey 不使用。

“准备同步文件夹”检查、保存目录，并在确认目录不存在时自动创建，包括缺失的父目录；已存在目录直接使用。同名文件、权限或网络错误会阻止操作，保留原配置。创建后再次核实目录，才启用同步。若中途失败，已创建的空父目录可能保留，不会自动删除。新安装默认使用 `/apps/remotely-save-next/笔记库名称`，实际可写范围取决于应用权限。

手机端显示“请到电脑完成设置”及电脑上的操作顺序，隐藏设置步骤并禁用相关操作。目前百度网盘同步仅支持电脑端，电脑上完成配置不代表手机端可以同步。历史记录仍可查看。

验收：电脑端登录后填写一个不存在且有权限的目录，点击“准备同步文件夹”，确认目录建立、绿灯亮起并可开始同步；再测试同名文件与无权限目录，确认错误就近显示且原配置不变。手机端检查提示与操作禁用。自动测试使用模拟接口，真实账号仍需实测。

## 0.1.9 文件同步诊断

同步队列保留底层错误原因；提示与历史记录可识别百度上传失败阶段、校验失败、HTTP 状态或百度错误码，不展示原始接口消息和令牌。此前文件上传错误被包装后丢失类型，统一误导为网络或权限问题。本版修复诊断信息，不代表已修复真实账号下尚未定位的文件上传失败。
