# WebDAV 普通用户界面设计 v1

项目：remotely-save-next。范围：WebDAV 设置、同步活动记录、必要反馈和删除保护。
百度与夸克的登录及设置流程另行讨论。本轮交付设计和可交互原型，尚未替换运行中的插件界面。

## 设计依据

使用本机 npm `ui-ux-pro-max-cli` 2.15.0 的离线技能资料，采纳适用于工具界面的极简层级、
渐进披露、字段就近报错、异步反馈、键盘操作和语义主题建议。
其设计系统检索两次均混入营销落地页模板，故未保存该通用模板；字体、配色、页面结构按 Obsidian 约束重新设计。
不引入 React、Tailwind、远程字体、图片或新的 UI 库。正式实现沿用 Obsidian Setting/Modal、现有 Lucide 图标和主题变量。

## 页面结构

共用页头：项目名、当前同步状态和一个主要按钮“立即同步”。
导航仅两项：“同步设置”“同步记录”。切换保留表单与列表展开状态，不刷新整个设置页面。

**同步设置**：

1. 连接：服务器地址、账号、密码；密码显示/隐藏；次要按钮“测试连接”。
2. 连接结果：在按钮下持续展示结果，成功时显示实际同步目录；失败就近给出可操作说明。
3. 自动同步：保存时同步开关、定时同步下拉（关闭、每 1/5/10/30 分钟）。
4. 冲突处理：保留较新版本（默认）、保留双方副本。不提供默认页强制覆盖本地/远端选项。
5. 一行提示“设置自动保存”；兼容设置集中到页底默认折叠的“高级设置”。

不展示长免责声明、专业认证选项、同步算法介绍、开发日志、上游商业账号、默认页统计图表。
高级入口保留旧配置的加密、排除规则、自定义目录等能力；普通用户无需打开即可使用。

**同步记录**：

- 按开始执行时间倒序，默认一页 20 条；只有记录超过一页才显示“加载更多”。
- 折叠行：执行时间、成功/部分失败/失败/已暂停/无变化状态、实际完成的上传/下载/删除数。
- 展开：按动作分组的仓库相对文件路径，以目录树展示。时间、触发方式、耗时作为轻量补充。
- 不记录笔记正文、文件历史版本、服务器完整地址、账号、密码或 Token；没有回滚、恢复按钮。
- 空状态：“还没有同步记录。完成一次同步后，这里会显示执行时间和统计信息。”
- 只记录实际同步尝试；连接测试不记入历史，预览不冒充已执行同步，正在执行的一条可持续更新。
- 默认保留最近 100 次，本地存储；本版不增加保留时长、搜索、筛选、导出或清空记录等设置。
- 单次文件列表分批展开，每批 50 项；计数保持全量。长路径可换行及复制，不只显示文件名。

## 关键交互

### 首次连接

填写三项 → 测试连接 → 显示结果及实际目录 → 立即同步。
测试中按钮为“测试中…”并禁用重复提交。测试失败保留输入和清晰的就近错误。
服务器地址失焦时校验 HTTP(S)、禁止 URL 内嵌账号密码；不改写密码前后空格，不禁止粘贴和密码管理器。
提交多项缺失时聚焦错误摘要，同时保留字段错误。账号是否允许为空按服务器认证方式判断，不能仅靠界面强制阻断匿名 WebDAV。

连接能力检查若实际写入/删除随机临时文件，按钮旁明确说明，不宣传为纯只读。
测试失败清理不完整时告知有临时残留。超时、认证失败、目录权限问题分别给出结果，不暴露原始敏感异常。

地址/账号/密码修改后，连接状态改为“连接信息已更改，请重新测试”，旧异步请求的结果不覆盖新输入。
配置编辑时短暂暂停自动触发；有效配置持久化和重新验证后恢复已启用的自动同步，避免半输入状态发送请求。
已经保存且经过当前配置验证的连接，可以再次打开设置后直接同步，无需每次点击连接测试。

### 同步触发与反馈

立即同步是唯一高强调按钮；连接测试和记录展开为次要动作。
同步中显示“同步中 · 已完成 N 项”，无法获取可靠总数时不用虚假进度条或百分比。
没有待同步文件时显示“没有变化”，记录计数均为 0。
保存时同步合并连续编辑，默认最后一次保存后约 2 秒触发；同步期间最多保留一个后续请求。
定时、保存和手动触发共享互斥。一次失败不反复弹窗，仅更新状态并记录原因；需要时用户可点立即同步重试。
同步进行中冻结连接、冲突策略和高级同步范围输入；定时及保存开关的调整对后续运行生效。

### 冲突

默认“保留较新版本”：两端均有修改时比较可靠修改时间；不能可靠判定时保留双方，不能任意覆盖。
“保留双方副本”：保留原文件并生成可识别的冲突副本，结果在记录中显示实际路径；命名沿用引擎最终实现。
选择新策略仅影响之后的同步，不宣称恢复已覆盖的文件。

### 大量删除/修改保护

保护默认启用，不增加普通用户开关。沿用引擎既有大比例修改/删除阈值，**不把该机制错误标成只保护删除**。
触发时暂停整个执行并显示明确统计：“本次计划修改 X 项、删除 Y 项，已暂停以保护文件。”
用户可“返回检查”（默认焦点）、展开待删除路径，或“确认本次变更”。
确认仅授权当前账号/目录/配置/同步计划的一次执行，不关闭全局保护；确认前重新校验计划，
计划变化时重新要求确认，自动任务不得自行确认。删除按钮使用危险样式，不用模糊的“继续”文案。
0.1.1 已实现确认弹窗和一次性执行授权；确认后重新扫描，计划变化则中止；不会关闭全局保护。

## 同步目录与兼容

当前客户端实际路径 = WebDAV 地址 + remoteBaseDir（未填时为仓库名）。
本轮界面改造必须保留已有地址、目录、加密及忽略配置；不能把“三个输入”理解为重新指定同步根目录。
目录显示是只读第四行，而不是第四个必填输入：例如“实际同步目录：…/dav/我的笔记/”。
首次配置默认使用专用仓库子目录；如用户需要指定目录，高级设置提供已有入口。
展示路径去掉 URL 内嵌凭据/敏感查询，允许查看安全的完整路径，不能复制带令牌的原始 URL。
更换实际目录或账号必须隔离/重新确认同步范围和历史，不能沿用不匹配历史推断删除。

## 视觉与适配

单列、轻分隔线、少量留白，不做多层大卡片、渐变、玻璃效果或仪表盘。
内容宽度上限约 720px，容器 560px 以下控件改为标签上、输入下；按设置窗格宽度适配，不只按整个屏幕宽度。
间距 4/8/12/16/24px；普通文本沿用 Obsidian 字体和字号，标题略放大，统计数字使用 tabular-nums。
颜色映射 `--background-primary`、`--background-secondary`、`--text-normal`、`--text-muted`、
`--interactive-accent`、`--text-error`、`--background-modifier-border` 等 Obsidian 主题变量。
原型独立提供明暗主题近似值，正式插件不覆盖用户主题。普通文本对比度目标至少 4.5:1，状态同时有文字而不是只靠颜色。
焦点轮廓可见；按钮、输入、折叠与标签页可用键盘。标签页实现方向键/Home/End 导航；
原型采用原生按钮及语义导航。密码显示按钮具有当前动作名称，记录展开具有 expanded 状态。
动效仅使用轻量颜色/透明度变化；减少动态效果设置下关闭动画。不依赖悬浮才可见的信息。

## 实现顺序与验收

1. 分离 WebDAV 简洁页与高级兼容页，保持配置/路径行为；完成原生主题和窄窗格布局。
2. 接入连接验证、立即同步、状态与调度互斥；保留既有删除保护，增加明确状态反馈。
3. 新增独立活动记录存储，按操作确认成功后计数；失败/暂停也记一条摘要。
   既有同步计划并非执行结果，不能直接转换为成功历史。
4. 接入文件目录展开、分页和一次性保护确认；用已绑定同步范围的实际操作结果生成记录。
5. 集中验证既有 WebDAV、多端/失败/重试/加密、设置迁移、计数、敏感字段脱敏和明暗主题/键盘/窄窗格。

原型 `webdav-prototype.html` 的统计与文件均为固定演示数据，所有请求都由本地交互模拟，
不访问网络、不读取实际配置、不执行同步。本轮只验证原型交互，不宣称正式功能已实现。

## 0.1.2 布局调整（用户确认后的修订）

服务器地址右侧放置测试连接按钮及状态灯。未测试为灰色、测试中黄色、成功绿色、失败红色；状态提供屏幕阅读器标签与悬浮提示。测试写删临时对象的说明收进按钮悬浮提示，不再占据页面段落。
服务器地址下方放置可编辑的同步目录，使用已有 remoteBaseDir，空值沿用仓库名。地址与目录组成完整路径并在目录下展示。原只读目录方案由此修订替代。修改目录后重新验证连接，保留原有同步范围隔离与大量变更保护。

## 0.1.3 密码控件调整

密码显隐改为输入框内右侧的眼睛图标，支持键盘操作并提供显示/隐藏密码的无障碍标签。原独立按钮位置改为连接配置与同步选项之间的分隔线。
